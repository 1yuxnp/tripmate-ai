# TripMate - AI 여행 플래너

## 📌 서비스 소개

**TripMate**는 여행 계획을 세우기 어려운 사용자를 위해 만든 **AI 여행 일정 추천 웹 서비스**입니다.

사용자가 여행지, 여행 기간, 여행 스타일을 입력하면 AI가 입력한 정보를 바탕으로 맞춤형 여행 일정을 생성해줍니다.

여행 계획을 직접 찾아보는 데 필요한 시간과 노력을 줄이고, 사용자의 취향에 맞는 여행 일정을 쉽게 만들 수 있도록 제작했습니다.

---

## 🎯 서비스 목적 및 타겟 사용자

### 서비스 목적

여행을 계획할 때 여러 정보를 직접 검색하고 일정을 구성해야 하는 불편함을 줄이고, AI를 활용하여 간편하게 여행 일정을 만들 수 있도록 하는 것을 목표로 합니다.

### 타겟 사용자

- 여행 일정을 직접 짜는 것이 어려운 사람
- 자신의 여행 스타일에 맞는 일정을 추천받고 싶은 사람
- 여행 계획에 많은 시간을 사용하기 어려운 사람

## ✨ 주요 기능

### 🏠 메인 화면

TripMate의 서비스와 AI 여행 추천 기능을 소개합니다.

메인 화면에서 AI 여행 추천 기능으로 이동할 수 있습니다.

### 🤖 AI 여행 일정 추천

사용자가 여행지, 여행 기간, 여행 스타일을 입력하면 AI가 맞춤형 여행 일정을 생성합니다.

**입력 예시**

- 여행지: 부산
- 여행 기간: 2박 3일
- 여행 스타일: 맛집과 카페를 좋아하는 여유로운 여행

사용자가 입력한 정보는 JavaScript를 통해 `/api/recommend` API로 전달됩니다.

Python 백엔드에서는 Gemini API를 호출하여 여행 일정을 생성하고, 생성된 결과를 다시 웹페이지에 표시합니다.

## 🧠 AI 기능 동작 방식

TripMate의 AI 추천 기능은 다음과 같은 과정으로 동작합니다.

사용자 입력  
↓  
JavaScript  
↓  
`fetch("/api/recommend")`  
↓  
Python Serverless Function  
↓  
Gemini API  
↓  
AI 여행 일정 생성  
↓  
JSON 응답  
↓  
JavaScript  
↓  
화면에 추천 결과 출력

사용자가 입력한 여행지, 여행 기간, 여행 스타일은 JavaScript에서 수집한 뒤 `fetch()`를 이용하여 Python API로 전달됩니다.

Python 백엔드에서는 Gemini API를 호출하여 사용자의 조건에 맞는 여행 일정을 생성하고, 결과를 JSON 형태로 반환합니다.

## ⚠️ 오류 및 실패 처리

필수 입력값이 비어 있는 경우 사용자에게 안내 메시지를 표시합니다.

> 여행지, 여행 기간, 여행 스타일을 모두 입력해주세요.

AI API 또는 서버에 오류가 발생하는 경우에도 오류 안내 메시지를 표시합니다.

또한 AI가 여행 일정을 생성하는 동안에는 로딩 상태를 표시하여 사용자가 현재 처리 중임을 알 수 있도록 했습니다.
